安安机器人

qtanglani 发布于 2026-07-25

零：闲话

经过我三四天的努力，安安机器人终于现实，也算是第一个好玩的小项目，现在稍微记录一下

(耽误了我好长时间的蔚蓝档案时间)

在能工智人的引荐下，使用NapCat+Nonebot搭建的机器人

之前下载QQ群聊报告的时候已经下载了NapCat，刚开始捣鼓了半天的NapCat一键安装，要么是显示12002，要么就是404。之后找到说可以安装 NapCat.Shell.zip,遂进行尝试，打开后发现和之前下载的一模一样。

NapCat就告一段落。

几年前安装python的时候，把一个文件夹内的所有文件都零零散散的安装到我的D盘里面，之后删除没删干净。那个版本的python就烂在了那里，连带着我的py路径一块。

之后装了个新py才解决，但路径确确实实就烂在那里了。

所以之后下载Nonebot的代码都加上了python -m,而不是py -m

之后还算顺利，Nonebot也安装成功了，顺便安了一个echo复读，测试测试

一：NapCat的安装与Nonebot的下载

就我来说NapCat.Shell.zip用的比较顺手，解压后双击launcher.bat，再扫码就可以

Nonebot需要用命令行下载

pipx install nb-cli

nb creat

模板选择bootstrap

名称自定义

适配器 选择Onebot V11

驱动器选择FastAPI

二：NapCat与Nonebot的连接

将NapCat终端的token复制下来，从二维码的上面找。

1.

在.env.prod文件中添加ONEBOT_ACCESS_TOKEN=你在NapCat中设置的access_token

2.

在终端中运行nb run启动NoneBot。观察控制台输出，找到类似FastAPI will start on ...的信息，记录下端口号

3.

在NapCap的WebUI中，找到第二个网络配置，并创建一个Websocket客户端

并在地址栏填写ws://127.0.0.1:你记录的端口号/onebot/v11/ws

至于名称那肯定是Anan_bot啦

4.

最后等待Nonebot终端连接就好，会有connect字样

三.插件的编写

在根目录下创建plugins文件夹，nb plugin create就可以，一定是根目录下有个叫plugins的文件夹。里面有__init__.py,在这里面编写插件

其中的.Anan_base,是我直接引用的前人的项目

github,直接复制进去就能运行

五.字体(可选)

字体建议下载一个，自带的太难看了

__init里面的font_path后面就是字体路径
